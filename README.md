# Landing page — Consultoria Social

Site institucional estático, responsivo e desenvolvido com HTML, CSS e JavaScript puro.

## Como visualizar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. Para publicar, envie a pasta completa para a hospedagem, mantendo a pasta `assets`.

## Arquivos
- `index.html`: conteúdo, estrutura e contatos.
- `style.css`: identidade visual, layout e responsividade.
- `script.js`: menu mobile e ano automático no rodapé.
- `assets/identidade-visual.jpg`: recorte da identidade visual enviada.
